This project initializes a front-end application with React deployed with Surge.

It aims to integrate the Spotify API that allows access to their database's music, tracks, and playlists.

This application allows users to add, eliminate, and update tracks and playlists to their Spotify account on demand.

It serves as an example of what React can do in the front end and also functioned as a milestone learning project to learn the reactive thinking of the framework and practice my skills.
